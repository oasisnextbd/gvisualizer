# gvisualizer

Simple, interactive walkthroughs of heat transfer derivations for ChE L3T1 (BUET). Each step shows a small animation and asks you to make the next decision in the derivation. Wrong answers explain why they fail.

## Modules

- **[Flat-Plate Boundary Layer](boundary-layer/)**: the integral (von Kármán) method for laminar flow over a flat plate, from scaling to δ/x = 4.64/√Re_x, plus the thermal layer and a profile-guess explorer. Notation follows Holman, *Heat Transfer*, Chapter 5.

No install needed. Open `boundary-layer/index.html` in a browser, or use the GitHub Pages link: https://oasisnextbd.github.io/gvisualizer/.
